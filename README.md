# Stopwatch

A professional, accessible stopwatch web application built with semantic HTML5, CSS3, and vanilla JavaScript.

## Features

- Hours / minutes / seconds / milliseconds display
- Start, pause, reset, and lap controls
- Scrollable, numbered lap list with per-lap delete
- Live statistics: total laps, fastest lap, slowest lap, average lap
- Export laps as CSV or copy them to the clipboard
- Light/dark theme toggle (persisted via `localStorage`)
- Fullscreen mode
- Keyboard shortcuts: `Space` start/pause, `L` lap, `R` reset
- Responsive layout and ARIA-labeled controls for accessibility

## Usage

Open [index.html](index.html) in a browser. No build step or dependencies required.

## Files

- [index.html](index.html) — semantic markup
- [style.css](style.css) — layout, theming, responsive styles
- [script.js](script.js) — stopwatch logic
